# Claude Code project guidance

Read and follow `AGENTS.md` as the primary project contract before making changes.

Also read:
- `docs/product-vision.md` for product scope
- `docs/learning/PHASE-WORKFLOW.md` for the learning/documentation workflow

Use pnpm only. Verify current Angular/Angular Material compatibility from official documentation (PrimeNG is not used). Keep the project bilingual (Arabic/English) with RTL/LTR support, owner-supplied Markdown content, accessible UI, and a Markdown guide for every completed phase.

Do not move to a later learning phase until the user approves the current phase.
