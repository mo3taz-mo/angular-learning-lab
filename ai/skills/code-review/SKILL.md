# Code Review Skill

Review in this order:
1. Correctness and user-visible behavior
2. Angular/TypeScript compatibility and build errors
3. Arabic/English locale and RTL/LTR behavior
4. Accessibility and keyboard interaction
5. Responsive layout and design consistency
6. Data handling and error states
7. Tests and verification quality
8. Dependency additions and version compatibility
9. Documentation and phase guide accuracy

Report findings by severity, with file/line references when available. Distinguish confirmed defects from questions or suggestions. Do not rewrite large areas just for stylistic preference. Do not claim tests passed unless they were executed.
