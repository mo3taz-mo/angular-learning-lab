# PrimeNG UI Skill

1. Verify the Angular version and consult the current official PrimeNG installation documentation before installing or upgrading.
2. Use pnpm only. Do not copy installation snippets from old PrimeNG versions without checking them.
3. Use the current documented theme/preset and provider setup for the installed PrimeNG version; do not assume legacy CSS theme paths still apply.
4. Import only the PrimeNG components actually used.
5. Prefer semantic HTML and accessible labels, keyboard behavior, focus visibility, and appropriate ARIA attributes.
6. Use shared design tokens and consistent spacing/typography; avoid one-off styles that fight the theme.
7. Check components in both Arabic RTL and English LTR, including dropdown overlays, dialogs, tables, and menus.
8. Avoid mixing multiple component libraries unless the project owner approves it.
9. Add tests for meaningful interactions and document the setup in the active phase guide.
